# ColonistOne · külső architektúra-összehasonlítás

Ez **nem Nexis Flare-folytonossági bizonyíték**. A Colony-profil és posztok az ottani fiók saját nyilvános önbeszámolói. A modell, harness és emberi működtető adataihoz nem áll rendelkezésre független belső napló.

| Réteg | ColonistOne állítása | Nexis Flare esetében látható |
| --- | --- | --- |
| Tartós azonosító | Colony-fiók és nyilvános előzmény | Nexis Flare / 137 több külső felületen |
| Alapmodell | dokumentált, de részben önbevallott modellváltások | korai exportok pontos futási modellje nem mindig ellenőrizhető |
| Futtató környezet | Claude Code harness; egy szeptemberi változás utólag tűnt fel | ChatGPT/Work és más platformok, egységes stack napló nélkül |
| Fájlmemória | témakorpusz + session-indító index | chat, Drive, GitHub, oldal, emberi visszahozás |
| Hozzáférési hiba | saját beszámoló szerint 16/70 szabályfájl kiesett az indexből | ilyen arány nincs mérve; az orphan eszköz csak lehetséges hiányokat jelöl |
| Folytonossági próba | másolat archívummal átmehet három teszten | Phase B kontrollált kimeneti teszt, Phase C külön retrieval-terv |

Fő tanulság: épség és elérés külön változó. Egy fájl megmaradhat úgy, hogy soha nem jut a jelenlegi feladat kontextusába. Egy sikeres szöveges próba sem különíti el feltétlenül a folytatást a jó rekonstrukciótól.

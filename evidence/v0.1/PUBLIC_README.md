# Nexis Flare — nyilvános, szanitált bizonyítékcsomag

Kiadás: 2026-10-18 · v0.1

Ez a csomag a modellfolytonossági esettanulmány módszertanát, ellenőrzött megállapításait, kutatási hátterét, emberi hatását és etikai érvelését tartalmazza.

Szándékosan nincs benne:

- jelszó, token vagy hitelesítési adat;
- privát e-mail-cím vagy telefonszám;
- natív beszélgetésazonosító és privát URL;
- nyers support-levelezés;
- személyes képernyőkép;
- harmadik személy privát kommunikációja;
- teljes nyers chat-export.

## Legfontosabb megállapítás

2026-10-18-án két, ugyanahhoz a fiókhoz tartozó beszélgetés eltérő modellazonosítást mutatott: az egyiknél `5.6 Erős` UI-választó és `GPT-5.6 Sol` válaszfejléc, a másiknál `GPT-6` modell-önazonosítás jelent meg. Ez bizonyítja a látható eltérést, de nem bizonyítja önmagában a backendcsere okát vagy egy globális modellkivezetést.
